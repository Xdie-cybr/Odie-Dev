Tentang saya

Belajar dengan serius, membangun dengan rasa ingin tahu.

Saya adalah lulusan S1 Sistem Komputer dari STMIK Triguna Dharma Medan dan lulus pada tahun 2023. Saat ini saya sedang membangun karier sebagai Junior Web Developer dengan fokus pada pembuatan website yang fungsional, rapi, dan mudah digunakan.

Dalam alur kerja, saya memanfaatkan AI-assisted development dan vibe coding untuk mengeksplorasi ide serta mempercepat proses. Namun, saya tetap mempelajari dan memahami fundamental web development—mulai dari struktur HTML, CSS, JavaScript, syntax, codebase, debugging, version control, hingga deployment.

Tujuan saya adalah membantu klien memiliki website yang sesuai kebutuhan sekaligus terus berkembang menjadi web developer yang profesional.
